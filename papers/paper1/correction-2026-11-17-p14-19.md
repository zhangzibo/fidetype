# CORRECTION NOTE (2026-11-17, P14-19): forward-chain table, fit prefix 0

**This is a correction note for the paper track. The paper text has not been changed.** Source: [P14-18/19 results](../../experiments/2026-11-17-p14-18-19-followups/results.md) (pre-registration `3d07cb4`).

## What changed
The B2T word-decoder settings (lm 1.0, edit penalty 12, bonus 3) were tuned once on 400 trials that cover all days. In the time-ordered (forward-chaining) tests, the fit prefix "day 1 only" (30 trials) should use a setting tuned on its own fit data. That setting is edit penalty 8 (P14-15). This prefix feeds V1 test day 3, V4 test day 4, V3 test day 2 and the staleness view. We reran these tests with it.
