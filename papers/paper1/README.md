## Build

From the repo root (Git Bash):

```bash
# 0. derived numbers (v1)
.venv/Scripts/python -I papers/paper1/analysis_r1.py
# 1. data figures (vector PDF) from committed JSON
.venv/Scripts/python papers/paper1/make_figures.py          # add --png for previews
# 2. compile the paper (two TeX passes + BibTeX run automatically)
cd papers/paper1/latex
mkdir -p build
/c/Users/zhang/tools/tectonic/tectonic.exe -X compile main.tex --outdir build --keep-logs
# 3. check: no undefined references or citations
grep -ciE "Citation .* undefined|Reference .* undefined" build/main.log   # must print 0
# 4. publish the draft
cp build/main.pdf ../draft-v1.pdf
```

PowerShell: `& C:\Users\zhang\tools\tectonic\tectonic.exe -X compile main.tex --outdir build --keep-logs`.

`latex/build/` is git-ignored. Only `draft-v0.pdf` (and later versions) is committed.

## Rules

- Every number in the paper comes from a committed result file or a wiki result page. Quote it as the source gives it.
- Missing data is marked in red with `\todo{...}` in the text. Never remove a `\todo` without filling the gap.
- References in `refs.bib` were checked against wiki source pages or the local text copies. Fields we could not check carry `% TODO-verify`. Do not add a reference nobody has read.
- To switch to the IOP *Journal of Neural Engineering* template: replace the block marked `CLASS` in `main.tex`; keep `sections/*.tex`.
