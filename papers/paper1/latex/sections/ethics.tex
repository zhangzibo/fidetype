\section{Ethics and data licences}
\label{sec:ethics}

This study uses only public, de-identified datasets. No new data were collected and no experiment with human participants was run, so no new ethics approval was required. \todo{the user decides the final wording of this statement; check the venue's policy on secondary use of public data.} We did not attempt re-identification. Raw recordings and participant data are not redistributed; our repository contains code, configurations, derived summary statistics and audit logs only. \Cref{tab:licences} lists every dataset and resource and how we use it.
