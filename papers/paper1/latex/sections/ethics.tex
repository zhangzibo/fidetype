\section{Ethics, data and code availability}
\label{sec:ethics}
\label{sec:availability}

This study uses only public, de-identified datasets; no new data were collected and no experiment with human participants was run, so no new ethics approval was required. The intracortical data come from a participant in the BrainGate2 pilot clinical trial \citep{card2024accurate}; the released copy-task file is CC0, we use only its logits and cue sentences, and we did not attempt re-identification. Quoted sentences are public copy-task cues, not the participant's own words. \todo{author decision: final ethics wording and the venue's policy on secondary use of public clinical-trial data.} No raw recordings or participant data are redistributed; \cref{tab:licences} lists all datasets and licences. The \nts{} specification, conformance suite, reference implementation, benchmark scorer and all experiment scripts are at \url{https://github.com/zhangzibo/fidetype} (Apache-2.0), without weights trained on SpanishBCBL or copied Brain2Qwerty code. Every table and figure is generated from committed result files by committed scripts; the experiment-level result files themselves need the public raw datasets and a local decode cache, which the repository's experiment folders describe with their exact commands. \todo{archive the paper commit with a DOI (e.g.\ Zenodo).} Decoders were trained on one AMD RX 7800 XT GPU. The trust layer runs on a CPU: on one thread of an AMD Ryzen 7 9800X3D, it took a median of 0.18--0.30\,ms per decision (95th percentile 0.49--1.06\,ms), measured while other jobs ran, against 45--232\,ms for the beam-search decoders.
