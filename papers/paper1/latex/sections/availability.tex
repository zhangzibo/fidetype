\section{Code and data availability}
\label{sec:availability}

The specification (\nts{} v0.1), the conformance suite with its golden vectors, the reference implementation (\texttt{fidetype}: adapters, decoders, trust layer, online risk control, audit log) and all experiment scripts and configurations are available under Apache-2.0 at \url{https://github.com/zhangzibo/fidetype}. The released code contains no model weights trained on SpanishBCBL (CC BY-NC 4.0) and no copied Brain2Qwerty code. Every table and figure in this paper is generated from committed result files; the figure script is \texttt{papers/paper1/make\_figures.py}, and the derived quantities of this revision (error among commits, 90th percentiles, pool risk) come from \texttt{papers/paper1/analysis\_r1.py}.
