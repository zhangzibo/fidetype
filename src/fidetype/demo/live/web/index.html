Fidetype replay demo
Connecting

A decoder guesses the text. Fidetype decides what gets typed.

We replay signals recorded from two people: one tries to speak with a brain implant, one types while wristbands read the muscle signals (EMG).

For each sentence, Fidetype types the guess, suggests it for the user to accept, or holds it back. Its promise: it almost never types wrong text without asking.

Today the decoders are weak, so most guesses are only suggested. Replay of recorded data, not live decoding.
