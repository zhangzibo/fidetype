Not live decoding. This page replays decoder output that was recorded earlier, at the speed it was recorded. For each sentence the Fidetype trust layer decides: commit (the text is typed), offer (the text is only a suggestion for the user to accept), or withhold (nothing is typed). The intended text is shown only to score the decisions.
