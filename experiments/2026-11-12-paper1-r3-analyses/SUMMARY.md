## Headline answers
1. **The CRC guarantee holds as a mean, not per deployment.** Over 50 random day-stratified fit-A / calibration / test splits, clean pure CRC gave a mean test wrong-commit of 0.0456 (B2T ours) and 0.0489 (published gate), both ≤ α = 0.05; sEMG 0.029 / 0.025 / 0. But 34–42 % of single B2T deployments were above α. **LTT max-rule** was above α in 8 % / 2 % of splits (≤ δ = 0.1) at mean 0.030 / 0.031: the natural primary safety row.
2. **Data reuse:** calibrating on the fit data raised pure CRC on B2T ours from 0.0456 to 0.0546 (paired +0.009, Wilcoxon p = 0.003; 58 % of splits above α). No effect on the published gate (+0.001, p = 0.72) or sEMG. Real for one decoder, but small against one split's spread (single-deployment MDE80 0.035): "the earlier 0.0625 was caused by reuse" is not supported.
3. **Binding:** the paper's split A (CRC not binding) is atypical. Over 50 splits the max rule changed plug-in decisions in 54 % (ours) / 34 % (published) of splits. In the paper's splits, **0.0588 → 0.0245 is entirely the policy-grid choice on fit-A** (commit_p 0.3 / guard 0.1 vs 0.5 / 0.5); temperatures and CRC contribute 0.
4. **Selective risk:** a guaranteed error among commits ≤ 0.10 (δ = 0.1) is reachable only for the published gate (11 % commits on average, none in 64 % of splits); our decoder, sEMG and MEG commit nothing at β ≤ 0.10 (ours: 0.3 % at β = 0.20).
5. **sEMG near-variant exclusion** (256 kept): trust 8.02 → 6.97, 4.68 → 4.08, 4.08 → 3.69 eWPM; on cross-subject, gaze typing is now faster than the layer ([−0.66, −0.23]).
6. **MEG:** no sentence-level guarantee is possible (needs ≥ 19 calibration sentences; the data set has 17 test / 11 val / 5 clean-cal sentences). Sentence-grouped instance CRC stayed ≤ α empirically (mean 0.016–0.019), because the decoder almost never has an eligible candidate.
7. **B2T decoder retune on fit-A only:** same grid point in both splits; nothing changes.
8. **Holm:** ours-A p = 0.012 → 0.072 (0.084 with the day-stratified reference). No Tab. 3 test is significant after correction.
9. **MEG seeds 0 / 1 / 2:** test CER 0.533 ± 0.051 (greedy), 0.503 ± 0.056 (beam + LM); seed 2 is worse (0.592). The layer committed nothing on every seed; on seed 2 gaze typing is faster ([−0.30, −0.05]).
10. **Run time:** 0.18–0.30 ms per decision (95th pct ≤ 1.1 ms), one CPU thread.
