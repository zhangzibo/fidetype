# Experiments

Each folder is one experiment run, named `YYYY-MM-DD-<task>-<short-name>`. A folder usually holds:

| File | What it is |
|---|---|
| `plan.md` (and often `config.json`) | The pre-registration: the question, the rules and the pass criteria, committed before any result |
| `results.md` | The results and the verdict, including negative results |
| `results/` | Aggregate result files (JSON). No raw recordings, no participant data and no weights |
| `*.py` | The code that ran the experiment |

The folder names and the texts use internal task codes. The roadmap that defines them is in [wiki/questions/roadmap-standard.md](../wiki/questions/roadmap-standard.md).
