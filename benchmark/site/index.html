Fidetype open benchmark v0.1

Neural text entry, scored from NeuralTextStream outputs. Every eWPM sits next to the no-BCI reference (gaze typing). Wrong-commit is marginal (wrong commits / all trials); error among commits is wrong commits / commits. CIs are cluster bootstraps at the track unit. No data and no weights are shipped: every dataset is download-only.

Safe WPM @ alpha (P14-05): words per minute of committed text that is exactly right, with a time penalty for each wrong commit, shown only when the policy has a certified CRC / LTT bound on the wrong-commit rate. Offered or withheld text counts 0 words. ABOVE alpha marks an entry whose measured test rate is higher than its stated alpha. Definition: docs/safe-wpm.md.

Tracks v0.1 (three tracks) and tracks v0.2 (seven tracks). v0.2 entries are scored by python -m fidetype.benchmark score <track> <submission> (docs/benchmark-submission.md). [RESEARCH ONLY] marks entries on non-commercial data; [partial] marks entries that cover only part of the scored units.

Rerun (P13-06): the rerun level of each entry (rescore, replay, full or no). Each track lists the exact rerun recipe of every entry: dataset version, split digest, adapter hash, scorer version and commands. Local paths are <placeholders>. Design: docs/hub-design.md section 5.

How to submit: benchmark/README.md. Generated by python -m fidetype.benchmark leaderboard; do not edit by hand.
