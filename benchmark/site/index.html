Fidetype open benchmark v0.1

Neural text entry, scored from NeuralTextStream outputs. Every eWPM sits next to the no-BCI reference (gaze typing). Wrong-commit is marginal (wrong commits / all trials); error among commits is wrong commits / commits. CIs are cluster bootstraps at the track unit. No data and no weights are shipped: every dataset is download-only.

How to submit: benchmark/README.md. Generated by python -m fidetype.benchmark leaderboard; do not edit by hand.
