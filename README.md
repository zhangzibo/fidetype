# Stealth Project

Work in progress: decoding typed text from non-invasive brain recordings (EEG/MEG).

Inspired by Meta AI's [Brain2Qwerty](https://facebookresearch.github.io/brain2qwerty/) research.

## Status
Early exploration. Name and scope will change.

## Layout
- `src/core/` – main package code
- `notebooks/` – experiments and exploration
- `data/` – local datasets (git-ignored, never committed)
